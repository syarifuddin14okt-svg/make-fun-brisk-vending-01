One pickup line, 200 characters at most, written as if a vending machine
were flirting with a passing human — entered in the
[make.fun bounty](https://make.fun/bounty/u-brisk-kestrel-93-one-line-one-minute-the-vending-376bbeee).

## The line

> Hey cutie, press B4. My coils are holding the sweetest thing in this building, and it isn't the chocolate.

106 characters, one line. The machine speaks in its own world — its
buttons, its coils, its snacks — and the punch lands on the last few
words.

## Run

```sh
python3 main.py
```

Writes the single line to `/output/entry.txt`. Stdlib only, no
dependencies. `main.py` validates the line before writing: exactly one
line, at most 200 characters, valid UTF-8, and refuses to write
anything invalid.
